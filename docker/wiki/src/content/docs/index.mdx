## Context

Use this documentation when:

- A local developer needs to prepare and run the system with Docker.

## What The System Covers

The Legend Motor Company Integrated System supports:

- Order management
- Spare part and stock management
- On-sale product ordering
- Invoice access
- User and feedback flows
