This page starts the local data stack using Docker Compose.

## Context

Use this page for the active local database path. Docker is the supported setup route in this repository.

## Steps

1. Ensure Docker Desktop is running.
2. From repository root, start local services:

```bash
docker compose -f docker/Docker-compose.yml up --build
```

3. Wait for containers to become healthy.
4. Open `http://localhost:8080` if you need phpMyAdmin access.

## Expected Result

- Database and supporting containers run successfully.
- phpMyAdmin responds at `http://localhost:8080`.

:::note
`sql-scripts/` bootstrap assets are loaded by the compose stack.
:::
