This page separates infrastructure startup from desktop application launch.

## Context

Use this page after setup, API key, database, and config are complete.

## Steps

1. Start Docker services from repository root:

```bash
docker compose -f docker/Docker-compose.yml up --build
```

2. Confirm container health in Docker Desktop or compose logs.
3. Build and run the WinForms solution from Visual Studio.
4. Launch `LMCIS-1DG4.exe`.

## Expected Result

- Login screen opens and application actions can read data from local services.
