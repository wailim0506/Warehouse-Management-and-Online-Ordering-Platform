This page prepares required local config before infrastructure startup.

## Context

Use this page first when starting setup on a new machine or a fresh local checkout.

## Steps

<Steps>
1. Clone the repository.
2. Copy `App.config.example` to `App.config`.
3. Keep local placeholders for API key and connection settings until later setup steps.
</Steps>

Use this baseline `appSettings` template:

```xml
<appSettings>
  <add key="DevMode" value="True"/>
  <add key="GoogleMapsApiKey" value="YOUR_LOCAL_DEV_API_KEY"/>
  <add key="ConnectionString1" value="server=localhost;port=3306;user id=root;password=rootpassword;database=itp4915m_se1d_group4;charset=utf8;ConnectionTimeout=30"/>
</appSettings>
```

## Expected Result

- `App.config` exists locally and contains local placeholder values only.

:::caution
Do not commit real API keys, production credentials, or customer data.
:::
