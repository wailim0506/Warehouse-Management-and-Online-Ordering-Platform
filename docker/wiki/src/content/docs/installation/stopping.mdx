This page defines normal shutdown steps for local development sessions.

## Context

Use this flow at the end of a local testing or documentation session.

## Steps

1. Close the WinForms application.
2. Stop Docker services from repository root:

```bash
docker compose -f docker/Docker-compose.yml down
```

## Expected Result

- Application process exits.
- Docker containers for the local stack stop cleanly.
