## Context

## Symptom Lookup

<CardGrid>
  <Card title="Docker services do not start" icon="seti:docker">
    Confirm Docker Desktop is running, then rerun `docker compose -f docker/Docker-compose.yml up --build`.
  </Card>
  <Card title="Database connection fails" icon="seti:db">
    Verify `ConnectionString1` in `App.config` and confirm port `3306` is available.
  </Card>
  <Card title="phpMyAdmin is unreachable" icon="seti:browser">
    Confirm stack startup and check whether port `8080` is already occupied.
  </Card>
  <Card title="Map images fail to load" icon="seti:map">
    Verify `GoogleMapsApiKey` value and Maps Static API restrictions.
  </Card>
</CardGrid>
