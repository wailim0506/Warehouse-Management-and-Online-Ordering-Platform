This page explains how to create a Google Maps Static API key and apply it to local app settings.

## Context

Use this page when map images or location-related screens need API-backed rendering.

## Steps

1. Open [Google Cloud Console](https://console.cloud.google.com/).
2. Create or select a project.
3. Enable **Maps Static API**.
4. Create an API key.
5. Restrict the key to Maps Static API and approved local usage restrictions.
6. Update `App.config`:

```xml
<add key="GoogleMapsApiKey" value="YOUR_LOCAL_DEV_API_KEY"/>
```

![Google Cloud project and API settings page](./img/google-cloud-console.png)

![Google Cloud API key creation dialog](./img/google-cloud-create-key.png)

## Expected Result

- The application can load map images without API authorization failures.

:::caution
Treat API keys as secrets. Never store real keys in committed source.
:::
