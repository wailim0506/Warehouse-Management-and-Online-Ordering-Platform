This page provides deeper validation steps after symptom lookup.

## Context

Use this page when setup or runtime checks fail and you need direct verification commands.

## Detailed Checks

1. Confirm containers are running and healthy.
2. Validate `App.config` values for `ConnectionString1` and `GoogleMapsApiKey`.
3. Check local ports `3306` and `8080` for conflicts.
4. Rebuild services after config or bootstrap changes:

```bash
docker compose -f docker/Docker-compose.yml up --build
```

5. Re-test service endpoints from [Services](/installation/services/).

## Expected Result

- Root cause is isolated to container startup, app config, port conflicts, or API key restrictions.
