This page lists endpoints to validate local runtime readiness.

## Context

Use these checks after starting Docker services and before deep troubleshooting.

## Service Endpoints

- WinForms executable: `LMCIS-1DG4.exe`
- phpMyAdmin: `http://localhost:8080`
- MariaDB host/port: `localhost:3306`

## Expected Result

- phpMyAdmin page loads.
- Database port `3306` is reachable.
- Desktop app can complete login without connection errors.
