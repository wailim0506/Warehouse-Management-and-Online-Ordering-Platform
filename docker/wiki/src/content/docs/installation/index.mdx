This page is the setup roadmap. Follow the sequence below in order to avoid configuration drift between the desktop app and local services.

## Context

Use this flow when setting up or resetting a local development environment.

## Setup Sequence

1. Prepare repository and local configuration.
2. Configure the Google Maps Static API key.
3. Start database and services with Docker Compose.
4. Apply local app connection settings.
5. Run the WinForms app.
6. Verify service endpoints.
7. Stop services when done.
8. Use troubleshooting pages for failures.

## Expected Result

- A new local developer can follow a single setup sequence without guessing page order.
