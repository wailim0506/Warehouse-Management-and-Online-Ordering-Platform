## What You'll Do

Set up local prerequisites, configure app settings, start Docker services, and run the WinForms app.

Use this sequence for local setup:

1. Complete repository and app setup.
2. Obtain a Google Maps Static API key.
3. Start the database and services with Docker Compose.
4. Configure `App.config`.
5. Run the WinForms app.

Docker is the default setup path in this repository.
