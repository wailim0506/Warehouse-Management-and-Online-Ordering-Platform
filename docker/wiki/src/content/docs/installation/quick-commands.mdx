This page provides grouped commands for the most common local operations.

## Context

Use these commands after you complete local config and when operating the Docker-backed environment.

:::tip
Run Docker commands from the repository root.
:::

## Start Stack

```bash
docker compose -f docker/Docker-compose.yml up --build
```

## Stop Stack

```bash
docker compose -f docker/Docker-compose.yml down
```

## Build Wiki

```bash
cd docker/wiki
npm run build
```

## Preview Wiki

```bash
cd docker/wiki
npm run preview
```

## Expected Result

- Docker containers start or stop without errors.
- Wiki build or preview commands complete successfully.
