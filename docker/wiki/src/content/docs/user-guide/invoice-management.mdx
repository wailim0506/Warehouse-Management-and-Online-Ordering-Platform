This page explains how invoice viewing connects to order workflows.

## Context

Use this workflow when a user needs invoice details for a selected order.

## Workflow

1. Open an existing order in the order workflow.
2. Trigger invoice view for that order.
3. Review invoice fields and linked order context.

## Expected Result

- Invoice details match the selected order and are available for verification.
