This page separates order lookup and order detail access into two clear tasks.

## Context

Use this workflow when finding an order by criteria and then reviewing its full details.

## Workflow

## Search Order

1. Open order management.
2. Enter search conditions.
3. Run the search.

### Expected Result

- Matching orders appear in the results list.

![Order management search interface with filters and results](./img/order-search-page.png)

## View Order

1. Select a record from the search result list.
2. Open the order detail screen.

### Expected Result

- Full order details load for the selected record.

![Order detail page opened from the order list](./img/order-details-page.png)
